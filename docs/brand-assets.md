# Talon Expeditions brand assets

The site uses the Talon Expeditions logo artwork supplied by Talon. Header/footer variants and favicon sizes should be derived from the supplied transparent PNG artwork rather than recreated as CSS or substituted with donor-template branding.

Current web asset roles:

- `talon-expeditions-logo-light.png`: full light wordmark for dark navigation/footer surfaces.
- `talon-expeditions-logo-dark.png`: full dark wordmark for light surfaces when used.
- `talon-expeditions-mark.png`: standalone eagle mark for compact brand applications.
- favicon/touch icons: derived from the standalone eagle mark.
